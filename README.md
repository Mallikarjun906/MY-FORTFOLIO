# Mallikarjun Badiger — Portfolio

## Run locally
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser, or use VS Code Live Server.

## Customize before publishing
- Replace the email address in `index.html`.
- Replace the GitHub, LinkedIn and Instagram `#` links.
- Add project GitHub/live-demo URLs if available.
- Replace/add a profile photo if desired.

The portfolio is responsive and uses plain HTML, CSS and JavaScript, so it can be deployed easily on GitHub Pages, Vercel or Netlify.
